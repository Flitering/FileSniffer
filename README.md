# FileSniffer

Утилита для Windows, которая находит папки и архивы **без важных для вас файлов** и помогает безопасно их удалить.

Обычные анализаторы диска (WizTree, WinDirStat, SpaceSniffer, TreeSize) показывают, *что* занимает место,
но не подсказывают, *что можно удалить без потерь*. Чистильщики пустых папок удаляют только совсем пустое.
FileSniffer занимает промежуточную нишу: вы говорите, какие файлы ценны (фото, документы, видео…),
и программа показывает всё, где их нет, в том числе внутри архивов.

**[Скачать последнюю версию (FileSniffer.exe)](https://github.com/Flitering/FileSniffer/releases/latest)**: установка не нужна.

## Когда это полезно

- Разобрать старые «Загрузки», рабочие папки или общий сетевой диск, где скопились распакованные дистрибутивы,
  временные файлы, логи и дубли архивов.
- Найти архивы, в которых нет ничего ценного, не распаковывая их.
- Перед переносом или бэкапом убедиться, что не теряете фото и документы.
- Найти «заброшенное»: фильтр «не изменялись N дней» плюс размер вместе с вложенными папками.

Когда FileSniffer **не нужен**: чтобы просто найти, что занимает диск, быстрее WizTree или WinDirStat.
Для очистки системы и кэшей лучше встроенная «Очистка диска» Windows.

## Возможности

- **Выбор важных типов файлов** (кнопка «Типы файлов…»): фото, документы, таблицы и презентации, видео,
  музыка, дизайн и чертежи, исходный код, почта и базы, плюс свои расширения. Настройки сохраняются
  в `%APPDATA%\FileSniffer\settings.json`.
- **Сканирование в фоне** с возможностью остановить. Показываются число файлов, размер самой папки и размер вместе
  с вложенными, дата последнего изменения, первые 10 имён и файлы метаданных.
- **Заглядывание в архивы** (ZIP, RAR, 7z) без распаковки, распознавание зашифрованных архивов,
  корректные русские имена в ZIP.
- **Статусы**:
  | Статус | Значение | Можно удалить |
  |---|---|---|
  | `Обычное` | ни в папке, ни во вложенных нет важных файлов | да |
  | `Важное` | в самой папке или архиве есть важные файлы | нет |
  | `Важное (во вложенных)` | важное есть во вложенных папках или архивах | нет |
  | `… (Зашифрован)` | архив под паролем, содержимое проверить нельзя | нет |
  | `Ошибка: …` | нет доступа или архив повреждён | нет |
- **Таблица** с сортировкой, поиском и фильтрами «Только неважные» и «Не изменялись N дней».
- **Удаление** в корзину или навсегда, «Выбрать все неважные» одной кнопкой, подсчёт освобождаемого места.
- **Распаковка** архивов и копирование папок.
- **Отчёт Excel** (`.xlsx`) с автофильтром.

## Безопасность

- Папка, в которой важное есть на любом уровне вложенности, защищена от удаления.
  Защищены также зашифрованные и нечитаемые архивы и сама сканируемая папка.
- Перед удалением каждый элемент **проверяется заново** по текущим настройкам: если после сканирования там
  появился важный файл, его пропустят. После смены настроек старые результаты сбрасываются.
- Удаляется только то, что лежит внутри сканируемой папки. Символические ссылки и junction-точки не раскрываются.
- При сканировании корня диска или системных папок выводится предупреждение.
- Распаковка защищена от *Zip Slip*: элементы с `../`, абсолютными путями, буквами дисков или ссылками
  отклоняются. Перед распаковкой проверяется свободное место.
- В отчёте Excel все строки записываются как текст, поэтому имена файлов вида `=HYPERLINK(...)` не станут формулами.

> Что считать «важным», решаете вы. Файлы, тип которых не отмечен, программа считает неважными.
> Начинайте с удаления в корзину.

## Запуск из исходников

Нужен Python 3.9+.

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python FileSniffer.py
```

Папку можно передать сразу: `python FileSniffer.py D:\Downloads`.

> Для **RAR** библиотеке `rarfile` нужна внешняя утилита: `UnRAR.exe` (из WinRAR) или `7z.exe` в `PATH`.

## Сборка и релиз

Локальная сборка:

```bash
pip install -r requirements-dev.txt
pyinstaller --onefile --windowed --name FileSniffer FileSniffer.py
```

Релиз собирается автоматически GitHub Actions ([release.yml](.github/workflows/release.yml)):
поднимите `__version__` в `FileSniffer.py`, обновите `RELEASE_NOTES.md` и запушьте тег `vX.Y.Z`.
