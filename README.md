# FileSniffer

Десктопная утилита для Windows: сканирует папку, показывает все подпапки и архивы (`.zip`, `.rar`, `.7z`) в одной таблице
и помогает безопасно убрать то, в чём нет важных данных.

## Возможности

- **Сканирование** папки в фоне: число файлов, размер, первые 10 имён, файлы метаданных (`.tmp`, `.db`, `.sys`, `.ini`, `.log`).
- **Заглядывание в архивы** без распаковки (ZIP, RAR, 7z), определение зашифрованных архивов,
  корректные русские имена в ZIP от архиваторов Windows.
- **Статусы**:
  | Статус | Значение | Можно удалить |
  |---|---|---|
  | `Обычное` | в папке и во всех вложенных нет важных файлов | да |
  | `Важное` | есть `.jpg`, `.jpeg`, `.png`, `.pdf`, `.doc(x)`, `.xls(x)` | нет |
  | `Важное (во вложенных)` | в самой папке важного нет, но оно есть во вложенных папках/архивах | нет |
  | `… (Зашифрован)` | архив под паролем, содержимое проверить нельзя | нет |
  | `Ошибка: …` | нет доступа или архив повреждён | нет |
- **Таблица** с сортировкой (числа и размеры сортируются как числа), поиском и фильтром «Только неважные».
- **Удаление** в корзину или безвозвратно, «Выбрать все неважные» одной кнопкой, подсчёт освобождаемого места.
- **Распаковка** архивов и копирование папок в выбранное место.
- **Отчёт Excel** (`.xlsx`) с автофильтром, сохраняется по кнопке.

## Безопасность

- Папка, в которой есть важное содержимое на любом уровне вложенности, защищена от удаления.
  Защищены также зашифрованные и нечитаемые архивы и выбранная корневая папка.
- Перед удалением каждый элемент **проверяется заново**: если после сканирования там появился важный файл, его пропустят.
- Удалить можно только то, что лежит внутри сканируемой папки. Символические ссылки и junction-точки
  при обходе не раскрываются.
- Распаковка защищена от *Zip Slip*: элементы с `../`, абсолютными путями, буквами дисков или символическими ссылками
  отклоняются. Перед распаковкой проверяется свободное место на диске.
- Отчёт Excel пишет все строки как текст, поэтому имя файла вида `=HYPERLINK(...)` не превратится в формулу.

## Установка и запуск

Нужен Python 3.9+.

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python FileSniffer.py
```

Папку можно передать сразу: `python FileSniffer.py D:\Downloads`.

> Для работы с **RAR** библиотеке `rarfile` нужна внешняя утилита: `UnRAR.exe` (из WinRAR) или `7z.exe` в `PATH`.

## Сборка .exe

```bash
pip install -r requirements-dev.txt
pyinstaller --onefile --windowed --name FileSniffer FileSniffer.py
```

Готовый файл появится в `dist\FileSniffer.exe`.

## Настройка

Списки расширений задаются в начале `FileSniffer.py`:
`NECESSARY_EXTENSIONS` (важные), `METADATA_EXTENSIONS` (метаданные) и `ARCHIVE_EXTENSIONS`.
